# 🤝 Contributing to the Digzopian Corpus

We welcome architects, philosophers, and coders to contribute to the **GameFi Core**.

## 🧬 Hermetic Contribution Protocol

1.  **Sovereignty First**: 
    - Ensure your code runs locally.
    - Avoid adding dependencies unless absolutely necessary.

2.  **Educational Value**:
    - Comment your code generously. Explain *why*, not just *how*.
    - Every PR should teach the reviewer something new.

3.  **Process**:
    - Fork the repository.
    - Create a branch: `feature/your-contribution-name`.
    - Commit with intention.
    - Open a Pull Request describing the philosophical alignment of your change.

## 🧪 Testing
Run `npm test` to ensure your changes respect the existing logic.
